# AgroTech - Projeto React

## 📋 Descrição do Projeto

O AgroTech é uma plataforma de soluções tecnológicas para agricultura sustentável, desenvolvida como parte do projeto PBL (Problem-Based Learning) da FIAP. O projeto visa otimizar a produção agrícola através de tecnologias inovadoras, contribuindo para a ODS 2 da ONU (Fome Zero e Agricultura Sustentável).

## 🎯 Objetivos

- Desenvolver soluções tecnológicas para otimização da produção agrícola
- Reduzir desperdícios e melhorar a eficiência no uso de recursos
- Promover agricultura sustentável e responsável
- Contribuir para a segurança alimentar global

## 🚀 Tecnologias Utilizadas

### Frontend

- **React 19.1.1** - Biblioteca JavaScript para construção de interfaces
- **Vite 7.1.2** - Build tool e dev server
- **Bootstrap Icons** - Ícones
- **Bootstrap 5** - Framework CSS para componentes

## 🔧 Funcionalidades Implementadas

- **Formulário de Contato**: Validação em tempo real, estados de loading, feedback de sucesso
- **Navegação Responsiva**: Menu mobile-first com React Router
- **Componentes Reutilizáveis**: Estrutura modular para fácil manutenção
- **Validação de Formulários**: Validação client-side com feedback visual
- **Estados de Loading**: Indicadores visuais durante operações assíncronas

## 🚀 Como Executar

### Pré-requisitos

- Node.js 18+
- npm ou yarn

### Instalação

```bash
# Entre na pasta do projeto
cd react-fiap

# Instale as dependências
npm install
```

### Desenvolvimento

```bash
# Inicie o servidor de desenvolvimento
npm run dev

# Acesse http://localhost:5173
```

### Build de Produção

```bash
# Gere o build de produção
npm run build

# Visualize o build
npm run preview
```
